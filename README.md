# Учётные алименты

Статический справочник для GitHub Pages. Источник показателя — итоговая среднемесячная номинальная начисленная зарплата работников организаций по полному кругу организаций по субъектам РФ, а не оперативная месячная зарплата.

`data/salaries.json` содержит только проверенные значения: `years[год][регион] = {salary, effective_from, source, checked_at}`. `effective_from` — подтверждённая дата применения показателя СФР. Отсутствующие данные не заменяются приблизительными.

Следующий этап: подключить официальный XLSX Росстата, проверить формат и заполнить исторические годы. Еженедельный процесс должен сравнивать все годы, сохранять историю изменений и требовать подтверждения даты перехода для режима «дата заявления». Пока источник не подключён, сайт намеренно не показывает чисел.
