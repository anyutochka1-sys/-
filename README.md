# Условные алименты

Отдельный справочник для GitHub Pages. Пункт 49¹ Правил единого пособия (постановление № 2330): ориентир для заявителя в разводе без судебного решения, в том числе с нотариальным соглашением ниже минимального размера. Годовые зарплаты берутся из официальной таблицы Росстата, а не усредняются по 12 месячным публикациям.

В `data/salaries.json` хранятся значения по 85 регионам за 2024 и 2025 годы. Данные за 2024 год используются для заявлений с 1 марта по 31 мая 2026 года. Опубликованное значение за 2025 год используется как ориентир с 1 июня 2026 года, но Росстат пометил этот год как предварительный. Например, в общей таблице Мордовия — 67 262 ₽, тогда как СФР сообщил 66 836,80 ₽. На странице указан предварительный статус и возможное отличие от расчёта СФР.

GitHub Actions (`.github/workflows/update-data.yml`) запускает проверку еженедельно во вторник. Импорт проверяет годовые столбцы, число регионов, пометку о предварительных данных и контрольный пример за 2024 год по Мордовии. Значения в архиве заменяются при изменении источника. Статус последней проверки — `data/import-status.json`. Если источник недоступен или контроль не пройден, прежние значения сохраняются.

Новый год применяется с первого числа месяца после официальной публикации окончательных данных Росстатом. Даты 2026 года подтверждены разъяснением СФР; будущие даты нельзя угадывать по календарю, их нужно подтвердить отдельно. Для 2027 года потребуется добавить источник годовой таблицы за 2026 год и дату публикации, прежде чем расчёт станет доступен для новых заявлений.

Для размещения: GitHub → Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save. После включения Pages адрес появится в этом же разделе. Существующий сайт в другом репозитории не затрагивается.
